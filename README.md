# Amatu Piano

Situs belajar piano dari dasar sampai jazz — https://amatu-id.github.io/piano/

- **Kamus chord**: 44 jenis chord (triad, nada tambahan, septim, jazz extended, altered) × 12 kunci, ejaan nada, inversi & voicing (shell, rootless A/B, drop 2, spread, kuart, upper structure).
- **Keyboard interaktif**: suara Salamander Grand Piano, mouse/sentuh, keyboard komputer, Web MIDI, deteksi nama chord, panduan tangga nada, rekam + unduh MIDI.
- **Teori**: tuts & nama nada, ritme, interval, tangga nada (17 jenis), membangun chord, chord diatonik, lingkaran kwint, voicing jazz.
- **Progresi**: 16 progresi (pop, blues, ii–V–I, tritone sub, rhythm changes…), 7 pola iringan, putar 12 kunci.
- **Latihan**: telinga (interval & chord), baca not (5 tingkat), tangga nada dengan penjarian, drill chord, metronom + pelatih kecepatan.
- **Lagu**: 12 lagu domain publik dengan falling notes — mode Dengar / Tunggu / Main + skor.

Statis, tanpa build: buka `index.html` lewat server lokal (`python3 -m http.server`).
Sampel piano: Salamander Grand Piano oleh Alexander Holm (CC-BY 3.0), dimuat dari tonejs.github.io.
